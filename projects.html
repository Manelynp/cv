Professional Training Project

PDF Form Editor & Data Processing Tool

Front-End Development Internship Project | Spain | Collaborative Project

A collaborative project developed with two classmates during a front-end development internship. The team independently researched and tested free JavaScript PDF libraries and different approaches before integrating the most suitable solutions into a shared ASP.NET project.

Key Features

  • Displayed and interacted with editable PDF forms using JavaScript PDF libraries.
  • Researched and tested free alternatives for PDF viewing and editing without using commercial licensed tools.
  • Extracted PDF form field names and user-entered values dynamically.
  • Structured extracted form data as JSON for future backend processing.
  • Tested and validated dynamic reading of PDF form inputs and values.
  • Added PDF form editing, ink annotation, signature capture, and form reset functionality.
  • Converted signature data to Base64 for processing.
  • Collaborated with two classmates to research, test, debug, and integrate individual solutions into the final project.

Technologies: ASP.NET, JavaScript, HTML, CSS, PDF.js, pdf-lib, Bootstrap, jQuery, JSON, Base64
