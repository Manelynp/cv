Travel Agency Web Application

Professional Training Project

An interactive front-end travel application that allows users to explore destinations, customize travel options, and receive dynamically calculated pricing.

  • Implemented dynamic pricing based on destination, travel dates, number of travelers, activities, meals, insurance, and transportation.

  • Developed client-side validation and a dynamic booking summary displayed in a modal.

PDF Form Editor & Data Processing Tool

Front-End Development Internship Project | Spain | Collaborative Project

A collaborative project developed with two classmates during a front-end development internship. We independently researched and tested free PDF libraries and different implementation approaches, then integrated the most effective solutions into a shared ASP.NET project.

  • Contributed to testing and implementing PDF form interaction, save/reset functionality, and dynamic product table management.

  • Collaborated with two classmates to test, compare, debug, and merge individual solutions into the final project.

Technologies: ASP.NET, JavaScript, HTML, CSS, PDF.js, pdf-lib, Bootstrap, jQuery, JSON, Base64
